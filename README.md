## About This Repository

This repository contains my final capstone portfolio for CS 499 at Southern New Hampshire University.

For this project, I revisited three applications I developed during my degree program. I reviewed their original implementations, identified areas that needed improvement, and made enhancements focused on software engineering, algorithms and data structures, and databases.

**[View My Portfolio](https://brandonburroughs17.github.io/cs499-portfolio/)**

## Capstone Projects

### 1. Travlr | Software Design and Engineering

A full-stack travel application built using the MEAN stack.

My enhancements focused on improving authentication, authorization, input validation, and application security. I also made changes to improve the overall structure and maintainability of the application.

[View Travlr Project](https://brandonburroughs17.github.io/cs499-portfolio/travlr.html)

### 2. Android Inventory | Algorithms and Data Structures

An Android inventory management application developed in Java.

I enhanced the application by implementing inventory searching, sorting, and low-stock filtering. I also improved input validation and account functionality to make the application easier to use.

[View Android Inventory Project](https://brandonburroughs17.github.io/cs499-portfolio/android-inventory.html)

### 3. Grazioso Salvare | Databases

A rescue animal dashboard built using Python, MongoDB, and Dash.

My enhancements focused on database configuration, CRUD operations, input validation, indexing, and dashboard functionality. I also updated the application to improve compatibility and maintainability.

[View Grazioso Salvare Project](https://brandonburroughs17.github.io/cs499-portfolio/grazioso-salvare.html)
